# 🩸 Tessera Socio Donatore Digitale — AVIS Tradate

> Modulo web per compilare, salvare e stampare la **tessera socio donatore** dell'AVIS Comunale di Tradate (VA).  
> Funziona interamente nel browser, senza backend, senza installazioni e senza registrazione.

---

## 📖 Descrizione

Il progetto nasce dall'esigenza di digitalizzare la **tessera socio donatore** dell'AVIS Comunale di Tradate, ancora oggi distribuita in formato cartaceo. La tessera cartacea si deteriora, si perde e non consente al donatore di consultare in modo semplice il proprio storico donazioni.

Questa web app single-file permette al donatore di:

- **Compilare** i propri dati anagrafici e sanitari direttamente dal browser;
- **Salvare** automaticamente le informazioni in locale (`localStorage`);
- **Stampare** o **salvare in PDF** una tessera completa e formattata;
- **Consultare** in un colpo d'occhio lo storico delle donazioni;
- **Accedere** rapidamente alle pagine informative del sito ufficiale di AVIS Tradate.

Il tutto in un'unica pagina HTML, senza server, senza database, senza cookie di tracciamento.
